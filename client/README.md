# VizGraph - Frontend Client

This is the React frontend for the VizGraph application. It provides an advanced data visualization platform with interactive charts and AI-powered insights.

## Technologies Used

- **React 18**
- **Tailwind CSS** for styling
- **Chart.js & React-Chartjs-2** for 2D charts
- **Three.js & React Three Fiber** for 3D visual elements
- **React Router** for navigation
- **Google OAuth** for authentication

## Getting Started

To run the frontend locally:

1. Ensure you have installed the dependencies:
   ```bash
   npm install
   ```

2. Create a `.env` file based on `.env.example` (or refer to the main repository `README.md` for environment variables).

3. Start the development server:
   ```bash
   npm start
   ```

The app will be available at [http://localhost:3000](http://localhost:3000).
